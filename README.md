# GBC EMU — эмулятор Game Boy / Game Boy Color

Эмулятор на C++17 с оболочкой на SDL2. Ядро (`core/`) не зависит от внешних библиотек,
оболочка (`app/`) отвечает за окно, интерфейс, ввод и звук.

## Возможности

- Процессор SM83 с точным тактированием (каждое обращение к памяти = 1 M-такт), таймер, прерывания
- Видеоконтроллер DMG и CGB: фон, окно, спрайты, палитры CGB, HDMA, OAM DMA, блокировка VRAM/OAM
- Картриджи: без контроллера, MBC1, MBC3 (с часами), MBC5; сохранения в `.sav` рядом с ROM
- Звук: два прямоугольных канала (со свипом), волновой и шумовой канал, вывод через SDL
- Интерфейс в ретро-стиле: библиотека игр из выбранной папки (карточки .gb / .gbc),
  переназначение клавиш, громкость, меню паузы, полный экран (F11), снимок экрана (F12)
- Сборка в один `GBCEmu.exe` без DLL (SDL2 и рантайм C++ линкуются статически)

## Проверка

| Тест | Результат |
|---|---|
| Blargg `cpu_instrs` | 11 / 11 |
| Blargg `cgb_sound` | 12 / 12 |
| Blargg `dmg_sound` | 9 / 12 (не реализованы особенности волновой памяти DMG) |
| Matt Currie `dmg-acid2`, `cgb-acid2` | изображение совпадает с эталоном |
| Собственные тесты `timing`, `ppu`, `mbc`, `dma`, `apu` | пройдены |

## Сборка (Windows)

Нужна Visual Studio 2019/2022 с компонентом «Разработка классических приложений на C++».
SDL2 скачивается автоматически при первой сборке.

```
build.bat          :: релизная сборка -> dist\GBCEmu.exe
build.bat test     :: сборка и прогон тестов
```

Запуск тестового ROM без окна: `out\build\x64-release\tests\run_rom.exe <rom.gb> [--dmg]`.

## Управление по умолчанию

| Game Boy | Клавиша |
|---|---|
| Крестовина | Стрелки |
| A / B | Z / X |
| Start / Select | Enter / Backspace |
| Меню паузы | Esc |

Клавиши, громкость и папка с играми меняются на экране настроек (F3) и хранятся в `gbcemu.ini` рядом с exe.
ROM-файлы игр в репозиторий не входят.
